# Support

Vanilla is a hobby project with one maintainer. There is no SLA. Replies usually come within a few weeks.

## Where to go

| You want to | Go to |
|---|---|
| Report a bug | [Bug report](https://github.com/Davidslv/vanilla-roguelike/issues/new?template=bug_report.yml) |
| Suggest a feature | [Feature request](https://github.com/Davidslv/vanilla-roguelike/issues/new?template=feature_request.yml) |
| Ask a question about the code | [Open an issue](https://github.com/Davidslv/vanilla-roguelike/issues) with the `question` label |
| Learn how it works | [docs/](docs/) and the [free web edition of the book](https://davidslv.uk/books/vanilla-roguelike/) |

Search existing issues first.

## In scope

- The game in this repository and its tests and tooling.
- Running it on the Ruby version in `.ruby-version`, on macOS or Linux.

## Out of scope

- Windows terminals. They may work but are not tested.
- Help with your own roguelike, beyond what the docs and the book cover.
- Errata or questions about the book's text. Use the contact details in the book.
