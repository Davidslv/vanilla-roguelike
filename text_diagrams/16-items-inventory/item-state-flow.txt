Item States in Detail:
=======================

On Ground:
──────────

┌────────────────────────────┐
│ Item Entity                │
├────────────────────────────┤
│ • PositionComponent        │
│   └─> row, column          │
│ • RenderComponent          │
│   └─> character: '!'       │
│ • ItemComponent            │
│   └─> name, value          │
│ • ConsumableComponent      │
│   └─> effect_type, value   │
│                            │
│ Visible in world           │
│ Can be picked up           │
└────────────────────────────┘


In Inventory:
─────────────

┌────────────────────────────┐
│ Item Entity                │
├────────────────────────────┤
│ • ItemComponent            │
│   └─> name, value          │
│ • ConsumableComponent      │
│   └─> effect_type, value   │
│                            │
│ NO PositionComponent       │
│ NO RenderComponent         │
│ (or ignored)               │
│                            │
│ Stored in:                 │
│ Player.InventoryComponent  │
│   @items = [item1, item2]  │
│                            │
│ Not visible in world       │
└────────────────────────────┘

Inventory Component Structure:
===============================

┌──────────────────────────────┐
│  InventoryComponent          │
├──────────────────────────────┤
│  @items = []                 │
│  @capacity = 20              │
│                              │
│  Methods:                    │
│  • add_item(item)            │
│  • remove_item(item)         │
│  • items()                   │
│  • full?()                   │
└──────────────────────────────┘

Example:
────────

player.get_component(:inventory)
  └─> InventoryComponent
      ├─> @capacity: 20
      └─> @items: [
            potion1,
            sword,
            scroll,
            potion2
          ]


Item Components:
================

ItemComponent:
──────────────

┌──────────────────────────┐
│  ItemComponent           │
├──────────────────────────┤
│  name: "Health Potion"   │
│  description: "Restores  │
│               health"    │
│  value: 50 (gold)        │
└──────────────────────────┘


ConsumableComponent:
────────────────────

┌──────────────────────────┐
│  ConsumableComponent     │
├──────────────────────────┤
│  effect_type: :heal      │
│  effect_value: 30        │
└──────────────────────────┘

Effect Types:
  • :heal → Restore health
  • :damage → Deal damage
  • :buff_attack → Increase attack
  • :buff_defense → Increase defense
  • :teleport → Random position


Creating an Item:
==================

Health Potion Example:
──────────────────────

item = Entity.new

item.add_component(
  PositionComponent.new(
    row: 5,
    column: 8
  )
)

item.add_component(
  RenderComponent.new(
    character: '!',
    color: :red
  )
)

item.add_component(
  ItemComponent.new(
    name: "Health Potion",
    description: "Restores 30 HP",
    value: 50
  )
)

item.add_component(
  ConsumableComponent.new(
    effect_type: :heal,
    effect_value: 30
  )
)

world.add_entity(item)
