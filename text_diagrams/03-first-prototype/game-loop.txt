The Game Loop
===============

Simple Flow:
------------

┌──────────────────┐
│ Process Input    │
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│ Update Game      │
│    State         │
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│ Render to        │
│    Screen        │
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│   Game Over?     │
└────────┬─────────┘
         │
    ┌────┴────┐
   No        Yes
    │          │
    │          ▼
    │    ┌─────────┐
    │    │  Exit   │
    │    └─────────┘
    │
    └──────┐
           │
           └─────> (Loop back to Process Input)


Detailed Loop:
--------------

    START
      │
      ▼
    ┌─────────────────────────────────┐
    │        GAME LOOP                │
    │  (Repeat until game ends)       │
    │                                 │
    │  1. ┌─────────────────┐         │
    │     │ Process Input   │         │
    │     └────────┬────────┘         │
    │              ▼                  │
    │  2. ┌─────────────────┐         │
    │     │ Update State    │         │
    │     └────────┬────────┘         │
    │              ▼                  │
    │  3. ┌─────────────────┐         │
    │     │ Render Screen   │         │
    │     └────────┬────────┘         │
    │              ▼                  │
    │  4. ┌─────────────────┐         │
    │     │  Check Exit?    │         │
    │     └────────┬────────┘         │
    │              │                  │
    └──────────────┼──────────────────┘
                   │
              ┌────┴────┐
             No        Yes
              │          │
              └──>LOOP   └──>END
