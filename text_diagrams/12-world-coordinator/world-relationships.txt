System Perspective:

┌────────────────────────────────────┐
│  MovementSystem                    │
│                                    │
│  def update(delta)                 │
│    # Ask world for entities        │

│  World                             │
│                                    │
│  def query_entities(types)         │
│    @entities.values.select do |e|  │
│      types.all? { |t|              │

│      }                             │
│    end                             │
│  end                               │
└────────────────────────────────────┘


Event Flow Through World:
==========================

1. System Emits Event:
   ────────────────────

   MovementSystem:
     emit_event(:entity_moved, {
       entity_id: "player-001",
       position: {row: 5, col: 3}
     })
          │
          ▼
   World Queue: [@event_queue << [:entity_moved, data]]


2. World Processes Events:
   ────────────────────────

   World.process_events:
     until @event_queue.empty?
       event_type, data = @event_queue.shift

       # Store in EventManager
       event_manager.publish(event_type, data)

       # Notify subscribers
       @event_subscribers[event_type].each do |subscriber|
         subscriber.handle_event(event_type, data)
       end
     end


3. Subscribers React:
   ───────────────────

   CollisionSystem (subscribed to :entity_moved):
     def handle_event(type, data)
       if type == :entity_moved
         check_collision(data[:entity_id])
       end
     end


Command Flow Through World:
============================

1. System Queues Command:
   ───────────────────────

   InputSystem:
     command = MoveCommand.new(player, :north)
     world.queue_command(command)
          │
          ▼
   World Queue: [@command_queue << command]


2. World Processes Commands:
   ──────────────────────────

   World.process_commands:
     until @command_queue.empty?
       command = @command_queue.shift
       command.execute(self)
     end


3. Command Executes:
   ─────────────────

   MoveCommand.execute(world):
     movement_system = world.find_system(MovementSystem)
     movement_system.move(@entity, @direction)

World Responsibilities:
========================

✓ Entity Management
  ├─> add_entity(entity)
  ├─> remove_entity(id)
  ├─> get_entity(id)
  └─> query_entities(types)

✓ System Management
  ├─> add_system(system, priority)
  ├─> remove_system(system)
  └─> update() - runs all systems

✓ Command Coordination
  ├─> queue_command(command)
  └─> process_commands()

✓ Event Coordination
  ├─> emit_event(type, data)
  ├─> subscribe(type, subscriber)
  └─> process_events()

✓ Level Management
  ├─> set_level(level)
  ├─> current_level
  └─> level_changed?

✓ Game State
  ├─> quit? flag
  ├─> display handler
  └─> current difficulty


Why World is Central:
======================

┌─────────────────────────────────────┐
│  Without World (Direct references)  │
├─────────────────────────────────────┤
│                                     │
│  MovementSystem ──> CombatSystem    │
│       ↕                    ↕        │
│  RenderSystem  ─────> InputSystem   │
│                                     │
│  • Tight coupling                   │
│  • Hard to test                     │
│  • Brittle dependencies             │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│      With World (Hub pattern)       │
├─────────────────────────────────────┤
│                                     │
│      MovementSystem                 │
│           │                         │
│           ↓                         │
│        World  ←── CombatSystem      │
│           ↑                         │
│           │                         │
│      RenderSystem                   │
│                                     │
│  • Loose coupling                   │
│  • Easy to test                     │
│  • Flexible architecture            │
└─────────────────────────────────────┘
