Collision Detection Flow:
==========================

┌────────────────────────────┐
│  Entity Moves              │
└──────────┬─────────────────┘
           │
           ▼
┌────────────────────────────┐
│  MovementSystem emits      │
│  :entity_moved event       │
└──────────┬─────────────────┘
           │
           ▼
┌────────────────────────────┐
│  CollisionSystem           │
│  subscribes to event       │
└──────────┬─────────────────┘
           │
           ▼
┌────────────────────────────┐
│  Get entity from event     │
└──────────┬─────────────────┘
           │
           ▼
┌────────────────────────────┐
│  Query all entities at     │
│  same position             │
└──────────┬─────────────────┘
           │
           ▼
┌────────────────────────────┐
│  For each other entity:    │
│  • Check collision type    │
│  • Handle interaction      │
└────────────────────────────┘


Position-Based Detection:
==========================

Simple Grid Collision:
──────────────────────

Grid at position [5, 3]:
┌──────────────────────┐
│   Row 5, Column 3    │
├──────────────────────┤
│                      │
│  Entity 1: Player    │
│    position: [5, 3]  │
│                      │
│  Entity 2: Monster   │
│    position: [5, 3]  │
│                      │
│  → COLLISION!        │
└──────────────────────┘


Query Implementation:
─────────────────────

find_entities_at_position(row, column)
  │
  ├─> Query world for all entities with PositionComponent
  │
  ├─> Filter by position:
  │     entities.select do |entity|
  │       pos = entity.get_component(:position)
  │       pos.row == row && pos.column == column
  │     end
  │
  └─> Returns: [Entity1, Entity2, ...]

Event-Driven Communication:
============================

Movement → Collision via Events:
─────────────────────────────────

MovementSystem               CollisionSystem
      │                            │
      ├─> Move entity              │
      │                            │
      ├─> Emit event               │
      │   :entity_moved            │
      │        │                   │
      │        └──────────────────>│
      │                            │
      │                            ├─> Handle event
      │                            │
      │                            ├─> Check collision
      │                            │
      │                            └─> Handle collision

No direct dependency!
MovementSystem doesn't know CollisionSystem exists.


Collision → Combat via Events:
───────────────────────────────

CollisionSystem              CombatSystem
      │                            │
      ├─> Detect collision         │
      │                            │
      ├─> Emit event               │
      │   :entities_collided       │
      │        │                   │
      │        └──────────────────>│
      │                            │
      │                            ├─> Handle event
      │                            │
      │                            ├─> Check if combat
      │                            │
      │                            └─> Process attack


Complete Interaction Example:
==============================

Player moves north onto Monster's cell:
────────────────────────────────────────

1. InputSystem
   └─> Queues MoveCommand

2. MovementSystem
   ├─> Executes move
   ├─> Updates player position to [5, 3]
   └─> Emits :entity_moved

3. CollisionSystem (subscribed to :entity_moved)
   ├─> Gets player entity from event
   ├─> Queries entities at [5, 3]
   ├─> Finds: [Player, Monster]
   ├─> Emits :entities_collided
   └─> Calls handle_player_monster_collision()

4. handle_player_monster_collision()
   ├─> Gets CombatSystem
   ├─> Calls process_attack(player, monster)
   └─> Combat resolves

5. CombatSystem
   ├─> Rolls for hit
   ├─> Calculates damage
   ├─> Applies to monster health
   ├─> Emits :combat_damage
   ├─> Checks if monster dies
   └─> If dead: emits :combat_death, removes entity
