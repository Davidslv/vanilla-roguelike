======================================

          │

┌─────────────────────┐

          ▼                     │

└─────────┬───────────┘         │
          │                     │
          ▼                     │
┌─────────────────────┐         │
│   Any Found?        │         │
└─────────┬───────────┘         │
          │                     │
     ┌────┴────┐                │
    Yes       No                │
     │         │                │
     ▼         ▼                │

└─────┘            ├─────┤            ├─────┤
                   │  B  │            │  C  │

                                      │  A  │
                                      └─────┘

Step 4: Backtrack
┌─────┐            (Pop D, try from C)
│  C  │            (No unvisited from C)
├─────┤            (Pop C, try from B)
│  B  │            ...continues
├─────┤
│  A  │
└─────┘


Characteristics:
=================
- Depth-first search approach
- Creates long, winding corridors
- Fewer dead ends than Binary Tree
- Fast and predictable (O(n))
- Uses stack for backtracking
- Good for dungeon-like mazes
